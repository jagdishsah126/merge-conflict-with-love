# 💌 merge-conflict-with-love

> *"Can we resolve this merge conflict over coffee? Why send a plain text when you can deploy an entire web application?"* 💻☕✨

A playful, interactive, coder-themed single-page website created to ask your special someone out on a date. Built with pure HTML5, CSS3, and modern Vanilla JavaScript — zero heavy dependencies, lightning-fast, and mobile-friendly.

---

## ✨ Features

- 🖥️ **Terminal Boot-Up Screen (`feelings_deployment.sh`)**: Realistic typing animation checking heart rate (`180 BPM`), loading `butterflies.dll`, and compiling courage before transitioning into the main experience.
- 🎨 **Aesthetic Developer Vibes**: Glowing dark theme with neon gradients, paired with `Plus Jakarta Sans` and `Fira Code`.
- 📊 **Candidate Technical Specs**: Humorous developer-style profile cards highlighting:
  - *Coffee & Food Pipeline* (99.99% reliability)
  - *Listening & Empathy API* (<10ms latency)
  - *Instagram Boyfriend Skills* (4K HDR angles)
  - *Date Itinerary Engine* (Bug-free plans)
- 📝 **Release Notes / Changelog**: Highlighting features like *Your Smile*, *Boring Days Patch*, and *Optimized Weekend Plans*.
- 🏃‍♂️ **Runaway "NO" Button**: The "No" button dodges the cursor/finger every time they try to click it, while cycling through witty developer error messages and growing the "YES" button larger.
- 🎶 **Web Audio Synthesizer**: 8-bit retro sound effects generated on the fly via the zero-dependency Web Audio API.
- 🎊 **Confetti & Official Date Ticket Pass**: Clicking "YES" triggers a celebratory confetti blast and allows them to pick their favorite date vibe and day to generate a personalized ticket.

## 🚀 Live Demo & Quick Start

### 1. View Locally
Simply clone or download this repository and double-click `index.html` to open it in your browser.

Or run a local server:
```bash
# Python 3
python3 -m http.server 8080

# Or with npx serve
npx serve .
```
Visit `http://localhost:8080` in your browser.

### 2. Live URL
🌐 **Official Live Site**: [https://askher.jagdishsah.com.np](https://askher.jagdishsah.com.np)

### 3. Deploy Free with GitHub Pages
1. Push this repo to your GitHub profile.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and click **Save**.
4. Set custom domain to `askher.jagdishsah.com.np` (already configured in `CNAME`).
